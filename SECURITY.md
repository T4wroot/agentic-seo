# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in this repository, please **do not** open a public issue.

Instead, please report security issues privately via:
- GitHub Private Vulnerability Reporting on this repository (under the **Security** tab)
- Or by contacting the maintainers directly.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to remediate the issue promptly.
